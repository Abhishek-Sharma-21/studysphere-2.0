# StudySphere 2.0

Developer Knowledge & Collaboration Platform.

## Vision

Learn together, share knowledge, solve problems, and build together.

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- AI: RAG and LLM integration (Phase 3)

## Branch Strategy

- main: Production
- dev: Development integration
- feature/\*: Individual features
- bugfix/\*: Bug fixes
